What will AI actually do?
Imagine a user enters an Ethereum wallet address.

Your application will:
1. Fetch the wallet's transaction history.
2. Collect transaction amounts, recipients, gas fees and timestamps.
3. Pass this structured data to an LLM.
4. Generate useful explanations and insights.

Three major AI features
1. Transaction Explanation

User asks: "What happened in this transaction?"

AI explains:
- Where the ETH went.
- How much was transferred.
- How much gas was spent.
- Whether the transaction succeeded.
2. Wallet Activity Q&A

User asks:
- "How much ETH did I spend this month?"
- "Which wallet did I interact with most?"
- "Summarize my last 10 transactions."
AI answers using the wallet's actual transaction data.

3. Unusual Activity Detection

AI helps explain patterns such as:
- Sudden large transfers.
- Repeated transfers to unfamiliar addresses.
- Unusual transaction frequency.

------------------------R A G ------------------------

1. Transaction-related questions
- Why did this transaction fail?
- Explain this transaction in simple English.
- What was the purpose of this transaction?
- Which transactions involved the highest gas fees?
2. Wallet activity
- What is the wallet's most common activity?
- Which addresses does this wallet interact with frequently?
- Has this wallet interacted with any suspicious addresses?
- How has this wallet's activity changed over time?
3. Blockchain knowledge
- What is an ERC-20 token?
- Why do Ethereum transactions require gas?
- What is the difference between ETH and WETH?
- How does a smart contract execute?
4. Risk analysis
- Why was this wallet assigned a high-risk score?
- What patterns make this transaction unusual?
- Has this wallet interacted with known scam addresses?
- What are the possible risks of interacting with this contract?
One important distinction
Not every question needs RAG.
Question	Best approach
What is my ETH balance?	Direct blockchain API
What was my largest transaction?	Python calculation
Explain this transaction	LLM + retrieved transaction data
What is an ERC-20 token?	RAG + LLM
Explain why this wallet looks risky	Risk analysis + LLM

Remember: RAG is particularly useful when answers depend on searching through a collection of information, rather than simply calculating a value.
